# Datenschutzerklärung gwAnd / Privacy policy gwAnd

Stand / as of 11.11.2026

## Deutsch

**Kurzfassung.** gwAnd ist ein Programm für einen Gramps-Web-Server, auf dem du ein Konto hast. Der Entwickler erhebt, speichert und empfängt keine Daten. Es gibt keine Konten beim Entwickler, keine Analyse, keine Werbung, keine Absturzberichte und keine Weitergabe.

**Verbindung zu deinem Server.** Die App sendet Anfragen nur an die Adresse, die du eingibst: Anmeldung, Suche, Änderungen, hochgeladene Fotos und Aufträge an den Server (Gesichts- und Texterkennung, Berichte, Export, KI-Assistent). Für diese Daten ist der Betreiber des Servers verantwortlich; ob und wohin der Server Fragen an den KI-Assistenten weiterreicht, legt er fest. Das Passwort wird nicht gespeichert, nur das Anmelde-Token. Eine unverschlüsselte Verbindung erlaubt die App nur im Heimnetz.

**Auf deinem Gerät gespeichert.** Einstellungen, Serveradresse, Benutzername, das Anmelde-Token, ein Lesezwischenspeicher mit zuletzt angesehenen Daten des Stammbaums und ein Zwischenspeicher für Karten. Alles liegt im geschützten Speicher der App, wird nicht in die Cloud gesichert und verschwindet beim Abmelden (Lesezwischenspeicher) bzw. mit der Deinstallation.

**Karte.** Öffnest du eine Karte, lädt die App Kartenkacheln von tile.openstreetmap.org. Dieser Server sieht deine IP-Adresse und die angesehenen Kartenausschnitte. Die App sendet keine weiteren Angaben. Siehe die [Datenschutzerklärung der OpenStreetMap Foundation](https://osmfoundation.org/wiki/Privacy_Policy).

**Benachrichtigungen, Kamera, Fotos.** Die Erinnerung fragt deinen Server im Hintergrund nach Jahrestagen und zeigt die Mitteilung lokal an. Fotos nimmst du mit der Kamera des Geräts auf oder wählst sie aus. Sie gehen an deinen Server.

**Berechtigungen.** Internet und Benachrichtigungen. Mehr braucht die App nicht.

**Deine Rechte.** Der Entwickler verarbeitet keine personenbezogenen Daten, bei ihm gibt es nichts zu löschen. Auskunft und Löschung betreffen den Betreiber deines Servers.

**Kontakt.** Fragen zum Datenschutz bitte als [Issue in diesem Repository](https://github.com/thobgg/gwAnd/issues).

## English

**In short.** gwAnd is a client for a Gramps Web server on which you have an account. The developer does not collect, store or receive any data. There are no accounts with the developer, no analytics, no advertising, no crash reports and no sharing.

**Connection to your server.** The app sends requests only to the address you enter: sign-in, search, changes, uploaded photos and jobs for the server (face and text recognition, reports, export, AI assistant). The operator of the server is responsible for this data; whether and where the server forwards questions to the AI assistant is up to the server. The password is not stored, only the sign-in token. The app allows an unencrypted connection only inside the home network.

**Stored on your device.** Settings, server address, user name, the sign-in token, a read cache with recently viewed family tree data and a cache for maps. Everything is kept in the app's protected storage, is not backed up to the cloud and disappears on sign-out (read cache) or when you uninstall the app.

**Map.** When you open a map, the app loads map tiles from tile.openstreetmap.org. This server sees your IP address and the map areas you view. The app sends nothing else. See the [OpenStreetMap Foundation privacy policy](https://osmfoundation.org/wiki/Privacy_Policy).

**Notifications, camera, photos.** The reminder queries your server in the background for anniversaries and shows the notification locally. You take photos with the device's camera or pick them. They go to your server.

**Permissions.** Internet and notifications. The app needs nothing more.

**Your rights.** The developer does not process personal data, so there is nothing to delete. Access and deletion concern the operator of your server.

**Contact.** Please send questions about privacy as an [issue in this repository](https://github.com/thobgg/gwAnd/issues).
